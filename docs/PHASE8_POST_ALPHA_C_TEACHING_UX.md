# Phase 8 Post-Alpha C: Guided Teaching UX

The normal workflow asks the reviewer what the Reader should show. Internal analyzer failure labels are derived from the authoritative snapshot.

## Workflow

1. Inspect the whole-sentence current partition without saving data.
2. Select the complete intended range and preview the whole-sentence before/after partition.
3. Start Teaching Review.
4. Confirm intended boundary and role.
5. Review the automatic diagnosis.
6. Choose confidence and an optional note.
7. Save Teaching evidence. Occurrence correction remains a separate explicit operation.
8. Return to reading.

Administrative controls, corpus governance, portability, packaging, evaluation, activation, and raw diagnostics remain available under Advanced Teaching tools.

Saving Teaching evidence does not tune, activate, or deploy the analyzer.
