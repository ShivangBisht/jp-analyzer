# Phase 10.1: Supervisor foundation

A Windows-oriented Python supervisor now validates machine-local configuration, prevents duplicate launcher instances, starts JP Analyzer and the Vite frontend without consoles, waits for health, records diagnostics in local application data, opens the Reader, monitors launcher-owned children, and shuts down only processes it owns.

This milestone does not change analyzer scoring, Teaching evidence, dictionary contents, governance, or tuning. VOICEVOX and AnkiConnect are optional degraded capabilities.
